# 🚀 PROYECTO: Speakeasy — Handover & Specs

## 📋 Resumen del Producto
Speakeasy es una app web para practicar inglés con conversaciones de voz en tiempo real con IA (niveles A1 a C2, acentos US/UK).

- Audio VAD (2-3s de silencio), transcripción en vivo con resaltado de errores en rojo/amarillo.
- Sistema de misiones (10-15 turnos), salud/vidas, minijuegos de 90s (Pronunciation / Speed Fill-in-the-Blank).
- Gamificación estilo Duolingo (Ligas, multiplicadores de XP, retos PvP, economía virtual).
- Estilo Apple Minimalist (Light/Dark mode, glassmorphism).

## 🛠️ Stack Técnico
- Frontend: React (Vite) + Tailwind CSS + Web Speech API
- Backend: Go (Golang) API REST
- IA / LLM: Gemini API / Groq (Llama 3)
- DB & Auth: Firebase (Firestore)
